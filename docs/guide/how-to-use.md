## 功能详解

### 🔍 智能导诊（症状 → 疾病）

1. 在首页点击"我有症状，想知道原因"
2. 输入您的症状（如"手麻"、"行走困难"）
3. **系统首先自动排查红旗症状（Red Flags）**
   - 如果命中红旗症状 → 立即显示警告，建议就医
   - 如果未命中 → 继续导诊流程
4. 系统给出可能的康复问题列表，点击进入对应疾病页面

### 📋 标准化评估（生成处方的前提）

**为什么需要评估？**
单纯输入疾病名称（如"脑卒中"）无法生成安全的运动处方。每个患者的功能状态、恢复阶段、合并症都不同，必须评估后生成个性化处方。

**评估内容（按亚专科不同）：**

| 亚专科 | 评估内容 |
|--------|---------|
| 神经康复 | 肌张力（Ashworth）、运动功能（Fugl-Meyer）、平衡（Berg） |
| 骨科康复 | 术后时间、ROM（关节活动度）、VAS疼痛评分 |
| 心肺康复 | RPE自觉强度、静息/运动心率、血压、Borg呼吸困难 |
| 老年康复 | 肌少症筛查（SARC-F）、跌倒风险（Berg）、共病情况 |

### 💊 运动处方（FITT-VP 格式）

生成的处方包含以下要素：

| 要素 | 含义 | 示例 |
|------|------|------|
| **F**requency | 频次（每周几次） | 3-5次/周 |
| **I**ntensity | 强度 | RPE 11-14 / 靶心率 60-80% |
| **T**ime | 时间（每次多久） | 20-60分钟（含热身/整理） |
| **T**ype | 类型 | 有氧运动、抗阻训练、神经肌肉训练 |
| **V**olume | 总量 | 每周 ≥150分钟中等强度 |
| **P**rogression | 渐进原则 | 每1-2周评估，逐步进阶 |

### 🔬 科学依据（证据标签）

每项训练都附有**循证证据标签**，点击可查看：

- 证据等级（Ia / Ib / IIa / IIb / III / IV）
- 来源（指南名称 / 文献标题）
- 文献 DOI 链接（可点击查看原文）

本网站支持**双模式切换**（右上角切换按钮）：

| 功能 | 患者模式（默认） | 专业模式 |
|------|----------------|---------|
| 语言 | 通俗易懂 | 专业术语 |

| 证据展示 | 简要标签 | 完整文献引用 + DOI 链接 |
| 适用人群 | 康复患者、家属 | 康复师、物理治疗师、医学生 |

## ⚠️ 安全注意事项

### 红旗症状（Red Flags）—— 立即就医！

如果您的以下症状，**请立即停止使用本网站，前往急诊**：

- 胸痛、胸闷、压榨性疼痛
- 突然面瘫、一侧肢体无力、言语不清
- 背部剧痛伴下肢无力或大小便失禁
- 剧烈头痛伴呕吐
- 静息心率 >100次/分 + 血压下降 + 血氧 <90%

### 运动安全原则

1. **循序渐进**：从低强度、短时间开始
2. **疼痛监测**：运动时 VAS 疼痛评分不应超过 3分（轻度疼痛）
3. **立即停止**：如出现胸痛、头晕、严重气促，立即停止运动
4. **专业指导**：本网站处方需在**康复医师指导下**执行
