# 循证医学证据等级

本网站所有康复方案均按照**牛津循证医学中心（Oxford CEBM）** 标准标注证据等级，确保康复处方的科学性和可靠性。

---

## 为什么需要证据等级？

康复医学在快速发展，并非所有"传统做法"都有科学依据。

> 循证医学（EBM）的核心：**将最佳研究证据与临床专业知识、患者价值观相结合**。

本网站标注证据等级，帮助您判断：
- 这个康复方案有多强的科学依据？
- 是来自大规模随机对照试验，还是仅来自专家意见？
- 我是否可以放心按照这个方案进行训练？

---

## 牛津循证医学中心证据等级（2011版）

### 治疗 / 干预 / 预后 类研究

| 等级 | 含义 | 研究类型 | 推荐强度 |
|------|------|----------|----------|
| **Ia** | 多项RCT的Meta分析 | 系统评价（Cochrane）、Meta分析 | ⭐⭐⭐⭐⭐ 强烈推荐 |
| **Ib** | 至少一项RCT | 随机对照试验（RCT） | ⭐⭐⭐⭐ 推荐 |
| **IIa** | 至少一项设计良好的非随机对照研究 | 队列研究（Cohort Study） | ⭐⭐⭐ 可选 |
| **IIb** | 至少一项设计良好的准实验研究 | 病例对照研究（Case-Control） | ⭐⭐ 谨慎参考 |
| **III** | 描述性研究 | 病例系列（Case Series）、横断面研究 | ⭐ 仅作参考 |
| **IV** | 专家意见 | 专家委员会报告、共识声明、临床经验 | 💡 经验指导 |

## 本网站三级证据架构

本网站的内容来源遵循以下优先顺序：

### 第一层：权威临床指南 ⭐⭐⭐⭐⭐

**优先使用**，代表当前最佳临床实践：

- APTA（美国物理治疗协会）临床指南
- WCPT（世界物理治疗联盟）声明
- 中华医学会物理医学与康复学分会 指南/专家共识
- 各专科权威学会指南（如 AHA/ACC 心肺康复指南）

### 第二层：系统评价与 Meta 分析 ⭐⭐⭐⭐

**用于支撑具体干预手段的有效性**：

- Cochrane Library 系统评价
- PubMed 高分综述（影响因子 >10）
- PEDro 数据库 高质量系统评价（PEDro 评分 ≥6）

### 第三层：高质量 RCT 研究 ⭐⭐⭐

**针对较新、较细分的康复技术**：

- 样本量 ≥50
- 随机对照设计
- 低偏倚风险（Cochrane RoB 工具评估）

## 局限性与声明

1. **证据等级会变化**：随着新研究发表，某个干预措施的证据等级可能升高或降低。
2. **个体差异**：即使证据等级为 Ia，也不代表对每一位患者都有效。
3. **本网站持续更新**：我们会定期审核内容，确保与最新证据一致。
