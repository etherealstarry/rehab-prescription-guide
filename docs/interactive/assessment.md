## 第二步：完成评估问卷

选择专科后，系统将加载对应的**标准化评估问卷**。

请根据您的实际情况填写，所有问题均为**评估处方所需的最低信息**。

> **提示**：如您不确定某些医学评估数值（如 Fugl-Meyer 评分），请选择"未评估"选项，系统将给出通用参考处方。

---

## 第三步：查看个性化处方

评估完成后，系统将根据您的评估结果，生成包含以下内容的个性化运动处方：

- **FITT-VP** 各要素（频次、强度、时间、类型、总量、渐进）
- **分阶段训练计划**（急性期 / 亚急性期 / 慢性期）
- **循证等级标签**（Ia / Ib / IIa...）及参考文献
- **注意事项与禁忌症**

## ⚠️ 红旗症状提醒

**在您开始评估前，请确认您目前没有以下红旗症状**：

| 红旗症状 | 可能原因 | 应对措施 |
|----------|---------|---------|
| 胸痛、胸闷、压榨性疼痛 | 心梗、肺栓塞、主动脉夹层 | 🔴 **立即拨打急救电话** |
| 突然面瘫 + 一侧无力 + 言语不清 | 脑卒中（中风）急性期 | 🔴 **立即就医** |
| 背部剧痛 + 下肢无力 + 大小便失禁 | 脊髓压迫 | 🔴 **立即就医** |
| 呼吸困难 + 端坐呼吸 + 咳粉红色泡沫痰 | 急性心力衰竭 | 🔴 **立即就医** |
| 剧烈头痛 + 喷射性呕吐 + 颈部僵硬 | 颅内出血 / 脑膜炎 | 🔴 **立即就医** |

> 如出现以上**任何一项**，请**立即停止使用本网站**并前往急诊科就诊。
