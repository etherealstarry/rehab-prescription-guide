## 📋 处方解读说明

### 如何理解 FITT-VP 各要素？

| 要素 | 含义 | 您需要做什么 |
|------|------|-------------|
| **F**requency | 每周训练次数 | 在日历上规划哪几天训练 |
| **I**ntensity | 运动强度 | 用心率或 RPE 量表监测强度 |
| **T**ime | 每次时长 | 包含热身 + 正式训练 + 整理 |
| **T**ype | 运动类型 | 按处方选择对应训练方式 |
| **V**olume | 每周总量 | 确保每周总运动量达标 |
| **P**rogression | 渐进原则 | 每 1-2 周评估后调整 |

### RPE 自觉运动强度量表（Borg 6-20）

| RPE 分值 | 感受 | 对应强度 |
|-----------|------|----------|
| 6-8 | 非常轻松 | 极轻度 |
| 9-11 | 很轻松 | 轻度 |
| 12-14 | 有点费力 | **中等强度（推荐）** |
| 15-17 | 很费力 | 高强度 |
| 18-20 | 非常费力（极限） | 极高强度（不推荐康复患者） |

## ⚠️ 安全注意事项

### 运动前必读

1. **红旗症状排查**：如运动中出现以下任一情况，**立即停止**并就医：
   - 胸痛、胸闷、压榨性疼痛
   - 突然面瘫、一侧肢体无力、言语不清
   - 剧烈头痛伴呕吐
   - 静息心率 >100 次/分 + 血压下降 + 血氧 <90%

2. **疼痛监测**：运动时 VAS 疼痛评分不应超过 **3 分**（轻度疼痛）

3. **循序渐进**：从低强度、短时间开始，每 1-2 周评估后再进阶

### 禁忌症（绝对禁止）

- 静息 SpO₂ <88% 且未吸氧时禁止运动
- 急性加重期（AE-COPD）禁止高强度训练
- 发病 <48 小时（脑卒中急性期）禁止高强度康复
- 术后 <2 周（ACL-R）禁止主动屈膝 >90°
