## 💊 核心康复原则（言语康复）

1. **代偿优先，功能为本**：急性期先保证营养与安全（鼻饲），同时尽早开始代偿性吞咽训练
2. **直接训练优于间接**：直接经口进食训练比单纯按摩/电刺激更有效（Ia 证据）
3. **个体化沟通辅具**：失语症患者应尽早配备沟通板/App，改善生活质量
4. **多学科协作**：言语治疗师、营养师、神经内科/康复科共同管理

## 📋 常用评估工具

| 评估工具 | 用途 | 判断标准 |
|---------|------|----------|
| **洼田饮水试验** | 筛查吞咽安全性 | III 级以上提示高风险 |
| **FOIS 量表** | 吞咽功能等级（1-7级） | 指导经口进食 vs 鼻饲 |
| **ABC 误吸风险评估** | 预测吸入性肺炎风险 | 结合 VFSS/FEES 使用 |
| **波士顿命名测验** | 失语症严重程度 | 用于基线 + 随访 |
