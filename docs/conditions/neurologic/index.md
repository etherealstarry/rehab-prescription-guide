## 🧠 神经康复涵盖疾病

| 疾病 | 简介 | 进入 |
|------|------|------|
| **脑卒中（中风）** | 脑血管阻塞/破裂导致的急性脑损伤，是中老年康复的第一大病种 | [查看详情 →](stroke.md) |
| 脊髓损伤 | 外伤/肿瘤/炎症导致脊髓功能受损，表现为损伤平面以下运动/感觉障碍 | [待补充] |
| 帕金森病 | 中脑黑质多巴胺能神经元变性，表现为静止性震颤、肌强直、运动迟缓 | [待补充] |
| 周围神经病变 | 糖尿病/化疗/免疫性疾病导致的外周神经损伤 | [待补充] |

## 💊 核心康复原则（神经康复）

1. **早期介入**：生命体征稳定后 24-48 小时即可开始床上康复
2. **任务导向性训练（TOT）**：以功能性任务为核心，而非单纯肌力量化
3. **重复性与强度**：大量重复（>300 次/次）才能诱发神经可塑性
4. **双侧训练**：同时调动健侧与患侧，促进半球间抑制平衡

## 📋 常用评估工具

| 评估工具 | 用途 | 适用时期 |
|---------|------|---------|
| **NIHSS** | 神经功能缺损程度（急性期） | 急性期 |
| **Fugl-Meyer（FMA）** | 上肢运动功能（0-66 分） | 恢复各期 |
| **改良 Ashworth 量表** | 肌张力（0-4 级） | 恢复各期 |
| **Berg 平衡量表** | 平衡功能 / 跌倒风险（0-56 分） | 恢复各期 |
| **Barthel 指数** | 日常生活活动能力 ADL（0-100 分） | 恢复各期 |
