## 🏥 重症康复涵盖问题

| 问题 | 简介 | 进入 |
|------|------|------|
| **ICU 获得性衰弱（ICU-AW）** | ICU 住院 >48h 后出现的全身性肌无力 | [待补充] |
| 长期卧床并发症 | 压疮、关节挛缩、DVT、肺炎等 | [待补充] |
| 呼吸机脱机训练 | 逐步降低呼吸支持，恢复自主呼吸 | [待补充] |
| 体位管理 | 预防压疮、体位性低血压、误吸 | [待补充] |

---

## 💊 核心康复原则（重症康复）

1. **早期介入**：生命体征稳定后 24-48 小时即可开始床上康复
2. **体位管理优先**：正确体位可预防压疮、关节挛缩和误吸
3. **被动 → 主动**：从被动关节活动 → 辅助主动 → 主动训练逐步进阶
4. **呼吸优先**：脱机前以呼吸肌训练和排痰技术为核心

## 📋 常用评估工具 |

| 评估工具 | 用途 | 目标值 |
|---------|------|----------|
| **GCS（格拉斯哥昏迷量表）** | 意识水平（3-15 分）| ≥13 分可考虑拔管 |
| **MRC 总分** | ICU-AW 肌力（0-60 分）| ≥48 分可离床训练 |
| **SOFA 评分** | 器官功能衰竭程度 | 越低越好，<6 分可考虑早期康复 |
| **Richmond 躁动镇静评分（RASS）** | 镇静深度（-5 至 +4）| -2 至 0 可配合康复 |
