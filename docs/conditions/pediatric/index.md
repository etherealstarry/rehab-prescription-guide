# 儿童康复

> 运动处方 · 循证指南 · 康复评估 |

---

## 👶 儿童康复涵盖疾病

| 疾病 | 简介 | 进入 |
|------|------|------|
| **脑瘫（Cerebral Palsy）** | 出生前/中/后非进行性脑损伤，表现为运动障碍 + 姿势异常 | [待补充] |
| 发育迟缓 | 大运动/精细运动/语言发育滞后于同龄儿童 | [待补充] |
| 自闭症谱系障碍（ASD） | 社会交往障碍 + 重复刻板行为，常伴感觉统合障碍 | [待补充] |
| 感觉统合障碍 | 感觉调节异常，表现为过度敏感或反应迟钝 | [待补充] |
| 唐氏综合征 | 21三体染色体异常，表现为肌张力低下 + 发育迟缓 | [待补充] |
| 肌营养不良 | 进行性肌无力和肌萎缩，最常见为杜氏型（DMD） | [待补充] |

---

## 💊 核心康复原则（儿童康复）

1. **游戏化康复**：以游戏/奖励机制提高儿童配合度
2. **发育里程碑追赶**：以正常儿童发育时间表为康复目标
3. **家庭为中心**：家长参与训练，将康复融入日常活动
4. **多模态刺激**：结合视觉、听觉、触觉多感官输入

## 📋 常用评估工具 |

| 评估工具 | 用途 | 适用年龄 |
|---------|------|----------|
| **GMFM-88 / GMFM-66** | 大运动功能（卧位翻身→行走跑跳）| 5月-16岁 |
| **FMFM（精细运动）** | 手部精细运动功能 | 3-12岁 |
| **PDMS-2** | 大运动 + 精细运动综合评估 | 出生-6岁 |
| **Sensory Profile** | 感觉统合能力 | 3-10岁 |
| **VMI（视觉-运动整合）** | 视觉与运动协调能力 | 2-18岁 |
