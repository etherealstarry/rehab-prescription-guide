# 老年康复

> 运动处方 · 循证指南 · 康复评估 |

---

## 👴 老年康复涵盖问题

| 问题 | 简介 | 进入 |
|------|------|------|
| **肌少症（Sarcopenia）** | 增龄性骨骼肌量、肌力、功能下降 | [待补充] |
| 跌倒风险 | 老年人致残/致死的主要原因之一 | [待补充] |
| 骨质疏松 | 骨密度下降，骨折风险增高 | [待补充] |
| 骨关节炎 | 关节软骨退变，膝/髋关节最常见 | [待补充] |
| 多病共存（Multimorbidity）| 同时患 ≥2 种慢性病，康复需综合考量 | [待补充] |

---

## 💊 核心康复原则（老年康复）

1. **安全第一**：所有训练必须在可耐受范围内，避免跌倒和骨折风险
2. **多重用药考量**：了解患者用药情况（如降压药→体位性低血压）
3. **温和渐进**：从低强度、短时间开始，每 2 周评估后进阶
4. **生活导向**：以 ADL 独立为目标，而非高强度运动表现

## 📋 常用评估工具 |

| 评估工具 | 用途 | 目标值 |
|---------|------|----------|
| **SARC-F 问卷** | 肌少症 5 项筛查（力量/行走/起立/爬楼梯/跌倒）| ≥4 分阳性，需进一步评估 |
| **Berg 平衡量表** | 平衡功能 / 跌倒风险（0-56 分）| ≥41 分低跌倒风险 |
| **TUG 测试** | 起立-行走-转身-坐回（秒）| <12 秒低跌倒风险 |
| **30 秒椅立测试** | 下肢肌力（30 秒内起立次数）| 年龄匹配常模 |
| **MMSE / MoCA** | 认知功能筛查 | MoCA ≥26 分正常 |
