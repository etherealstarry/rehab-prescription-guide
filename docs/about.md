# 关于康复处方指南

> 基于循证医学（EBM）的康复运动处方查询平台

---

## 🎯 项目愿景

让每一位康复患者、康复师和物理治疗师，都能**免费、便捷地获取基于最新循证医学证据的标准化康复运动处方**。

---

## 👥 适用人群

<div class="grid cards" markdown>

-   :material-account-heart:{ .lg } **康复患者 & 家属**
    了解自己的康复问题，获取安全的运动处方，在家也能科学康复。
-   :material-stethoscope:{ .lg } **康复医师 & 治疗师**
    作为临床决策的辅助参考，快速查阅各疾病的最新循证康复方案。
-   :material-school:{ .lg } **康复专业学生**
    系统学习循证康复知识，了解 FITT-VP 处方原则和证据等级。

</div>

---

## 💊 核心功能

| 功能 | 说明 |
|------|------|
| 🔍 **智能导诊** | 输入症状 → 排查红旗症状 → 给出可能的康复问题 |
| 📋 **标准化评估** | 按亚专科（神经/骨科/心肺等）完成多维度评估问卷 |
| 💊 **FITT-VP 处方生成** | 基于评估结果，自动生成标准化运动处方 |
| 🔬 **循证证据展示** | 每项训练附证据等级（Ia→IV）和文献 DOI 链接 |
| ⚠️ **Red Flags 拦截** | 输入症状后先排查急危重症，保障安全第一 |

---

## 📚 循证等级说明

本网站所有康复方案均按 **牛津循证医学中心** 标准标注证据等级：

| 等级 | 含义 | 推荐强度 |
|------|------|----------|
| **Ia** | 多项RCT Meta分析 | ⭐⭐⭐⭐⭐ 强烈推荐 |
| **Ib** | 至少一项RCT | ⭐⭐⭐⭐ 推荐 |
| **IIa** | 设计良好的非随机对照 | ⭐⭐⭐ 可选 |
| **IIb** | 准实验研究 | ⭐⭐ 谨慎参考 |
| **III** | 描述性研究 | ⭐ 仅作参考 |
| **IV** | 专家意见 | 💡 经验指导 |

[详细了解 →](guide/evidence-levels.md)

## 🏥 覆盖的康复亚专科

| 亚专科 | 涵盖疾病 / 问题 |
|--------|--------------|
| 🧠 神经康复 | 脑卒中、脊髓损伤、帕金森病、周围神经病变 |
| 🦴 骨科康复 | 前交叉韧带重建、肩袖修复、关节置换、腰痛 |
| 🫀 心肺康复 | COPD、心梗术后、心力衰竭、新冠后康复 |
| 👶 儿童康复 | 脑瘫、发育迟缓、自闭症谱系、感觉统合障碍 |
| 👴 老年康复 | 肌少症、跌倒风险、骨质疏松、多病共存 |
| 🛏️ 重症康复 | ICU获得性衰弱、长期卧床、呼吸机脱机训练 |
| 🗣️ 言语康复 | 吞咽障碍、失语症、构音障碍、认知沟通障碍 |
