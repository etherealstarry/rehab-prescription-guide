## 使用说明

### 如何在网站代码中引用
在 `disease-knowledge-base.js` 的 `evidence` 字段中，使用以下格式：

```
证据等级 + 年份 + 来源缩写
例：`Cochrane Review 2023; APTA 眩晕CPG 2023`
```

### 如何更新本资料库
1. 搜索最新指南（WebSearch：`[疾病] rehabilitation guideline 2024 2025`）
2. 确认指南的发布机构和年份
3. 在对应章节添加新条目
4. 更新文件顶部的「最后更新」日期
5. 提交 commit（格式：`docs: 更新证据资料库，新增[指南名称]`）
